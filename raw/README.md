# Fuentes originales

Deposita aquí artículos, PDFs, notas de lectura, imágenes y datos que quieras conservar como evidencia.

Los archivos de esta carpeta son la fuente de verdad: no se modifican durante la elaboración de la wiki. Para cada fuente procesada se crea una nota de síntesis en `../wiki/fuentes/`.

Los adjuntos de Obsidian pueden guardarse en `assets/` si más adelante los necesitas.
